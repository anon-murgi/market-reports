# Market Reports

Static HTML5 reports for production hosting.

Add your files to the repository root (or subfolders) and push to `main`.

## GitHub Pages

If Pages is enabled for this repo (**Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)`**), the site URL is:

`https://anon-murgi.github.io/market-reports/`

Use root-relative asset paths or a `<base href="...">` tag if you publish from a subfolder.
